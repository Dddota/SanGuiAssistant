# 归心流程设计

## 游戏内流程（已通过截图确认）

1. 世界地图底部有「归心」入口按钮。
2. 点击进入后弹出**城池列表弹窗**，显示当前可归心的城池（如羌道、武都、狄道等），每座城可归心 3 次，每行有「前往归心」按钮。
3. 点击「前往归心」进入**转盘界面**：大转盘抽奖，左侧进度条（0-250 转累积奖励），右下角「剩余:N」次数，「跳过动画」已勾选，右上角 X 关闭。
4. **没有「全部归心」按钮**，必须逐个城池操作。

## 自动化流程

```
主界面 → 点击归心入口 → 弹出城池列表
  → 对列表中每个城池：
      点击"前往归心" → 进入转盘
        → 点击"归心"按钮 ×3 次（repeat:3）
        → 点击 X 关闭 → 返回列表
  → 若列表可滚动，滑动翻页继续下一批
  → 找到右下角"剩余:0" 或 列表无城池可归心 → 结束
→ 返回主界面
```

## 结束判定

- 城池列表无「前往归心」按钮（无可归心城池）。
- 或转盘界面「剩余」次数为 0。

## 异常处理

- **奖励/确认弹窗**：识别并关闭。
- **网络断开**：尝试恢复。
- **超时**：on_error 兜底重试。

## Pipeline 节点设计

```
guixin_start
  └─ 找归心入口按钮 → 点击进入
      └─ guixin_city_loop（循环处理每个城池）
           ├─ 找"前往归心"按钮 → 点击
           │    └─ 找"归心"转盘按钮 → 点击（repeat:3, interval:1s）
           │         └─ 找关闭 X → 点击
           │              └─ 回到 guixin_city_loop
           └─ 找不到"前往归心" → 滑动列表 → 重试（最多滑动 5 次 → 结束）
```
