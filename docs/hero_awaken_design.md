# 武将觉醒识别（搁置）

## 状态
代码已写好，未实机验证。暂时搁置，后续需要时再启用。

## 功能描述
扫描武将列表时，识别武将是否已觉醒、觉醒品阶是几阶。

## 识别逻辑
- 在左侧武将列表中，每个武将名的**左侧**（x 更小）找「神」字
- 「神」字**正下方**的数字即为觉醒品阶
- 有神字但没读出数字时，默认按 1 阶算
- 未检测到「神」字时，awaken_level = 0（未觉醒）

## 代码位置
- `app/data/user_hero.py` —— `UserHero.awaken_level: int = 0`
- `app/core/hero_scanner.py` —— `_ocr_list_names()` 内检测「神」字 + 品阶数字，通过 `_read_detail(awaken_level=...)` 传入
- `app/view/peijiang_tab.py` —— 详情卡片头部显示「觉醒 N 阶」标签（粉色 #e91e63）

## 已知问题 / 待验证
1. 「神」字 OCR 可能识别不准（可能识别成「觉」「升」等形似字），需实机看识别结果后加同义词匹配
2. 品阶数字位置（「神」字下方距离）默认 < 50px，可能需调整
3. 未觉醒武将左侧是否有其他装饰元素干扰，需确认
