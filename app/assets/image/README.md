# 模板图目录

本目录存放「三归小助手」运行所需的**模板图 / 识别图**（按钮、入口、弹窗等）。

## 为什么这里没有放图

为尊重与保护游戏著作权，**游戏截图类素材不进入 Git 仓库**（`.gitignore` 已忽略本目录下的所有 `*.png`）。请自行在使用时按需提供。

## 如何提供模板图

1. 在游戏内运行 / 调试时，对照需要识别的元素（如"归心系统入口""转盘按钮"等）进行截图。
2. 将截图命名为与代码 / pipeline 引用一致的名称，放入本目录（源码运行会读取 `<项目根>/app/assets/image/`）。
3. 重新启动程序即可生效。
